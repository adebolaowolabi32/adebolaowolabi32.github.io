## Preview

Run `python3 -m http.server 8080` in this directory and open http://localhost:8080. GitHub Pages publishes the master branch.

The demos use fictional data. Each case study explains what runs in the browser and what I tested locally.

Each `Cynthia_Owolabi_CV_*.pdf` has a matching HTML source. Generate PDFs with Chromium print-to-PDF using CSS page size and background printing. `resume.html` is the current CV selection page; `resume-revised.html` is the revised baseline source. `Cynthia_Owolabi_Resume.pdf` is an archived original with superseded dates and must not be overwritten.
